# Weather Dashboard

Responsive weather dashboard using JavaScript and the Open-Meteo API to display current and forecast weather data.

## Live Demo

https://weather-app-project-ashy-xi.vercel.app

## Features

- Search weather information by location
- Current weather conditions and temperature
- Feels-like temperature, humidity, wind and precipitation data
- 7-day forecast
- Hourly forecast
- Day selection for hourly data
- Metric and Imperial unit switching
- Responsive layout for mobile and desktop

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Open-Meteo API
- Vercel

## What I Practiced

This project strengthened my understanding of consuming REST APIs, handling asynchronous JavaScript, working with dynamic data, updating the DOM, managing user interactions and building responsive interfaces.

## Run Locally

1. Clone the repository.
2. Open the project folder in VS Code.
3. Start it with a local development server.
4. Open the local URL in your browser.

No API key is required for Open-Meteo.
